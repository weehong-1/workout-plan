Rules

  • Navigation bar on the four main screens; detail screens get a top app bar and, where there are actions, a floating toolbar.
  • One primary action per screen as an extended FAB.
  • Progress is shown with wavy indicators; charts use metric colours only.
  • Spacing on a 4 dp grid; 16 dp screen margin; touch targets 48 dp.
  • Numbers animate in: values count up, charts draw left to right; both stay still when the phone asks for reduced motion.
